# Calculation decisions

Interpretations made where `SPEC.md` leaves room. Code lives in `packages/core`; tests pin each rule.

| Topic                | Decision                                                                                                                                                                                                                                                                        |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Quantities           | Integer micro-shares (1 share = 1,000,000), like money micros, so fractional positions net to exactly zero. Core, DB and API use micro-shares; the UI shows plain shares (e.g. 0.5). Migration 0001 rescaled existing rows. (Changed in Phase 4; originally whole shares only.) |
| Fees sign            | `commission` and `otherFees` are stored as non-negative costs; importers flip IBKR's negative commissions.                                                                                                                                                                      |
| Tie-breaking         | Same timestamp → broker exec ID (executions with one sort first) → `id` (insertion order).                                                                                                                                                                                      |
| Rejected fills       | Invalid executions and sells exceeding the position are reported and **not applied**; callers must block commit while errors exist.                                                                                                                                             |
| Partial exits        | Cost removed at the running average cost (`mulDiv`, half away from zero); the last sell takes the exact remainder so Σ realised = proceeds − cost.                                                                                                                              |
| Open trades          | `grossPnl` / `netPnl` / `returnPct` are null until closed. `realisedNet` = realised gross − all fees paid so far.                                                                                                                                                               |
| Holding period       | NY dates. Calendar days = date difference. Trading days = NYSE sessions in (open date, close date], so Fri→Mon = 1, same day = 0.                                                                                                                                               |
| NYSE calendar        | Rule-based holidays (incl. Good Friday, Juneteenth from 2022, Sat New Year not observed) plus a small list of special closures. Early closes are ignored.                                                                                                                       |
| Initial risk         | Planned-risk override (if > 0) wins. Otherwise (first entry − stop) × first qty; null if no stop or stop ≥ entry → trade excluded from R stats.                                                                                                                                 |
| Break-even           | `                                                                                                                                                                                                                                                                               | net | < threshold` (default $1). Win rate = wins ÷ (wins + losses). Expectancy $ averages over all trades incl. break-evens. |
| Streaks              | Close order; break-even trades neither extend nor break a streak.                                                                                                                                                                                                               |
| Profit factor/payoff | Null (shown as “n/a”) when there are no losses.                                                                                                                                                                                                                                 |
| Equity points        | One point per NYSE trading day. Events on weekends/holidays roll to the next trading day; events before the start land on day 1; events after the end are dropped.                                                                                                              |
| External flows       | Only deposits and withdrawals are external (excluded from TWR). Dividends, interest and non-trade fees count as performance.                                                                                                                                                    |
| TWR                  | Daily return = (equity − today's external flow − yesterday's equity) ÷ yesterday's equity (flows at end of day); 0 when yesterday's equity ≤ 0.                                                                                                                                 |
| Max drawdown         | $: on cumulative performance (realised P&L + income), peak starting at 0, so withdrawals are not drawdowns. %: on the TWR index, peak starting at 1. Both reported as ≤ 0.                                                                                                      |
| Sharpe / Sortino     | Daily TWR returns, risk-free 0, annualised × √252. Sharpe uses sample stdev; Sortino uses downside deviation over all days (target 0).                                                                                                                                          |
| Cumulative R         | Close order, trades without R skipped and counted; R drawdown measured from a peak starting at 0.                                                                                                                                                                               |

## Persistence and API (Phase 2)

| Topic               | Decision                                                                                                                                                                                                                                                                                          |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Regrouping          | Every execution insert/update/delete regroups the symbol in the same transaction; a grouping error (e.g. oversized sell) rolls the change back with HTTP 422.                                                                                                                                     |
| Stable-key matching | A trade row is a candidate for a new group when its `stable_key` execution is in that group. The kept row is the one already keyed to the group, else one with journal data, else the oldest key; it is re-keyed to the group's first execution, so journal data follows an earlier-dated insert. |
| Orphans             | Rows left without a group keep their data and get `orphaned_at` (extra column, not in the original schema). They are hidden from lists unless `?orphaned=include                                                                                                                                  | only`, can be deleted only explicitly, and are un-orphaned if their stable-key execution becomes a group's first fill again. Rows with no journal data are deleted. |
| New trade           | `POST /api/trades` refuses (409) while a position in the symbol is open, or if the fill would land inside an existing trade.                                                                                                                                                                      |
| Add fill            | `POST /api/trades/:id/fills` refuses (409) if the fill would end up in a different trade (e.g. a buy dated after the close).                                                                                                                                                                      |
| Tickers             | The API requires uppercase tickers (400 otherwise); list filters accept any case.                                                                                                                                                                                                                 |
| Timestamps          | Must carry `Z` or an offset; stored normalised to UTC. Cash flows also accept a plain date.                                                                                                                                                                                                       |
| Trade list dates    | `from`/`to` filter on the NY close date (open date for open trades), inclusive. Default sort: open time, newest first. Totals are over closed trades (fees over all listed trades).                                                                                                               |
| Open-trade holding  | Measured up to "now".                                                                                                                                                                                                                                                                             |
| Cash-flow signs     | Deposits > 0, withdrawals < 0, other types any non-zero amount.                                                                                                                                                                                                                                   |
| Tags                | Names are unique across kinds. The setup is `trades.setup_tag_id` (SETUP tags only); `trade_tags` holds MISTAKE/CUSTOM tags. Delete-with-reassign and merge require the same kind.                                                                                                                |
| Seed                | Deterministic (seeded PRNG). Refuses a non-empty DB; `--force` wipes every table first.                                                                                                                                                                                                           |

## UI (Phase 3)

| Topic          | Decision                                                                                                                                                                                                       |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Times in forms | Entered and displayed as New York wall-clock time; converted with `nyLocalToUtc` / `toNyLocal`. A time skipped by spring-forward shifts forward; an ambiguous fall-back time takes the first (EDT) occurrence. |
| Prices         | Fill prices show 2 decimals, or 4 when sub-cent. Averages (entry, exit, cost) are shown to the cent.                                                                                                           |
| Open trades    | The list's P&L column shows realised net so far (tooltip says so); return % and R stay empty until closed.                                                                                                     |
| Add fill       | Open trades show the form (default Sell). Closed trades hide it behind "Add a missed fill…" (default Buy). Sells larger than the open position are blocked inline.                                             |
| Forms          | Inputs clear on submit and are restored if the save fails, so fast entry can't race the response. Deletes use a two-click confirm button, never a browser dialog.                                              |
| Screenshots    | PNG/JPEG/WebP/GIF only, detected from the file's bytes; 10 MB limit; stored as `data/uploads/<tradeId>/<uuid>.<ext>`; files are removed with the screenshot or the orphaned entry.                             |
| Filters        | Trade-list filters and sort live in the URL query string so other pages can deep-link.                                                                                                                         |

## Imports (Phase 4)

| Topic             | Decision                                                                                                                                                                                                                                                                |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| IBKR source       | The **Activity Statement CSV** (not a Flex Query), since that is the export available. Rows are per order (partial fills aggregated) and carry no execution id. Times are New York time.                                                                                |
| Imported          | USD stock trades; USD transaction fees (added to the matching fill's other fees, else booked as a FEE); USD deposits/withdrawals, dividends, withholding tax (as a negative DIVIDEND), interest and fees.                                                               |
| Skipped (listed)  | Other asset classes (e.g. Forex conversions), non-USD rows, cancelled trades, total rows. Each appears in the preview with its line number.                                                                                                                             |
| Base currency EUR | Option A: performance is tracked in USD. EUR deposits/withdrawals are skipped; enter them as their converted USD amount. Multi-currency stays out of scope for v1.                                                                                                      |
| Share classes     | IBKR's `BRK B` / `MOG A` become `BRK.B` / `MOG.A`.                                                                                                                                                                                                                      |
| De-duplication    | Broker id when present, else `fp:<sha256 of row content>#<n>` (n numbers identical rows in one file so both are kept). Re-importing a file, or an overlapping statement, reproduces the same ids, so known rows are skipped. Stored in the UNIQUE `external_id` column. |
| Duplicate files   | A file whose SHA-256 matches a committed import is flagged; committing needs "Import anyway", which adds only missing rows.                                                                                                                                             |
| Preview           | A dry run in a rolled-back transaction: new / duplicate / problem rows and the trades that would be created or changed. The parsed rows are stored on the batch so commit inserts exactly what was previewed.                                                           |
| Blocking errors   | Fills that would sell more than is held block the commit (long-only). Unreadable rows are listed and left out.                                                                                                                                                          |
| Undo              | Deletes the batch's executions and cash flows and regroups; refused if later fills depend on imported ones. Journal data added to imported trades is kept (orphaned), never deleted.                                                                                    |
| Regroup fallback  | If a trade's stable-key fill disappears (deleted, or an import undone), its journal row moves to the group holding most of its previous fills instead of being orphaned.                                                                                                |
| Generic CSV       | Header row required. The mapping sets columns, date format, NY or UTC times and side values; without a side column a negative quantity is a sell. No time → 12:00. Commission sign is ignored (always a cost). Mappings can be saved as named presets.                  |
| Private data      | Real statements live in `private/` (gitignored, not linted). Test fixtures are synthetic.                                                                                                                                                                               |
